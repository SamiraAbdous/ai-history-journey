# رحلة تاريخ الذكاء الاصطناعي — لعبة تعليمية تفاعلية

**من إعداد: د. سميرة عبدوس** · جامعة أمحمد بوقرة بومرداس · مقياس «مقدمة في الذكاء الاصطناعي» (المحاضرة 2 / الأعمال الموجهة 2)

خريطة طريق ثنائية اللغة (العربية / English، زر التبديل أعلى الصفحة) من 1943 إلى 2026 في تسع محطات + محطة إضافية «خرافة أم حقيقة؟». في كل محطة: قصة قصيرة، بطاقات مصطلحات (English · Français · العربية)، وتحدٍّ (اختيار متعدد، صح/خطأ، ترتيب أحداث) يفتح المحطة التالية. نقاط ونجوم، وشرح فوري عند الخطأ، وخلاصة الرحلة في النهاية.

## التشغيل
- ملف واحد فقط: `index.html`. يعمل بفتحه مباشرة في أي متصفح، أو عبر GitHub Pages.
- لا يحتاج خادمًا ولا مفاتيح ولا مكتبات خارجية (الخطوط من Google Fonts فقط؛ يعمل بخط النظام عند انقطاع الإنترنت).
- يحفظ تقدم الطالب واسمه على جهازه (localStorage) ولا يرسل أي بيانات.

## النشر على GitHub Pages
1. أنشئي مستودعًا (مثلًا `ai-history-journey`) وارفعي `index.html` و`README.md`.
2. Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `/ (root)` → Save.
3. بعد دقيقة يظهر الرابط: `https://<اسم-المستخدم>.github.io/ai-history-journey/`.

## التعديل
المحتوى كله في مصفوفة `S` داخل `index.html` (محطة = كائن فيه `story`، `ev` الأحداث، `terms` المصطلحات، `qs` الأسئلة). لتعديل سؤال غيّري نص `q` والخيارات `o` ورقم الإجابة `a` (يبدأ من 0) والشرح `w`.
