## البنية
```
index.html              الفهرس (يعرض تقدم الطالب في كل وحدة)
assets/app.css          التصميم المشترك (فاتح/داكن، RTL/LTR)
assets/engine.js        المحرك المشترك: الاسم، المراحل، التبويبات، الأسئلة، النقاط
assets/widgets.js       الأنشطة المشتركة: التصنيف، الترتيب، الادعاءات، السيناريو
modules/<الوحدة>/index.html   محتوى كل وحدة (بيانات + أنشطة خاصة بها)
```

## التشغيل
- صفحات ثابتة بلا خادم ولا مفاتيح ولا مكتبات خارجية (الخطوط من Google Fonts فقط؛ يعمل بخط النظام عند انقطاع الإنترنت).
- يحفظ تقدم الطالب واسمه ولغته على جهازه (localStorage) ولا يرسل أي بيانات.
- للتجربة محليًا يُفتح `index.html` مباشرة في المتصفح.

## النشر على GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `/ (root)` → Save. يظهر الرابط بعد دقيقة.

## التعديل
محتوى كل وحدة في استدعاء `Course.init({...})` داخل `modules/<الوحدة>/index.html`:
- `sections`: مصفوفة المراحل؛ كل مرحلة فيها `story` (الشرح)، `terms` (المصطلحات)، `activity` (النشاط) و`qs` (الأسئلة).
- لتعديل سؤال غيّري نص `q` والخيارات `o` ورقم الإجابة `a` (يبدأ من 0) والشرح `w`.
- كل نص يُكتب بالصيغة `{ar:'...', en:'...'}`.
